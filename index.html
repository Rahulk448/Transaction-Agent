How This AI Agent Thinks

The Plain-English Architecture & Decision Guide (Explained so clearly even a 15-year-old gets it!)

1 The Agent is a Detective (Bayes Rule)

Starting with a Hunch, Updating with Clues

Before your agent sees any transaction details, it starts with a starting baseline (a Prior): "In normal credit card transactions, 90% are legitimate and 10% are fraud."

When a transaction arrives, the agent acts like a detective collecting clues. If the purchase is at 3:00 AM from a foreign city, that clue (an Evidence Signal) pushes the fraud chance up. The agent uses Bayes' Rule to multiply probabilities together and arrive at its new updated hunch (the Posterior Belief).

2 The "Confusion Meter" (Shannon Entropy)

Measuring Uncertainty in Bits

How confused is the AI right now? We measure confusion using Shannon Entropy (H) in units called bits:

  • 0.0 Bits: Total Certainty! "I am 100% sure this transaction is good."
  • 1.0 Bit: Maximum Confusion! "It is a 50/50 coin flip, I have no idea!"

If a new clue takes the agent from 90% sure down to 50/50, the agent's entropy goes UP because the clue destroyed its certainty!

3 Why 44.4%? (Derived Decision Math)

Balancing Money Loss vs. Annoyed Customers

Why doesn't the agent just block everything that looks 51% suspicious? Because blocking a good customer has a cost!

Cost of Blocking Good Customer (False Positive) = $8.0
Cost of Approving Stolen Card (False Negative) = $10.0
Break-Even Threshold p* = 8.0 / (8.0 + 10.0) = 44.4%

The math proves that if fraud chance is above 44.4%, blocking the card loses less money on average than letting it go through!

4 Smart Asking (Active Sensing EIG/Cost)

Don't Guess — Ask Efficiently!

When the agent is stuck in the middle (between 20% and 75% fraud chance), it chooses HOLD to ask the customer for verification.

But asking someone for a password or calling them causes customer friction. So the agent computes Expected Information Gain per Unit Cost (EIG/Cost):

Push Notification: High Clarity / Low Cost = 0.35 bits/cost (WINNER!)
Manual Phone Call: High Clarity / Massive Cost = 0.08 bits/cost

The agent automatically picks the Push Notification because it destroys the most confusion for the least customer annoyance.
